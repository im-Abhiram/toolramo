IANA Port Range Classifications
0 – 1,023 System / Well-Known

Assigned by IANA to ubiquitous network services (HTTP, SSH, DNS, DHCP, Telnet, NTP). On POSIX operating systems, binding to these ports requires superuser (root) privileges.

1,024 – 49,151 Registered Ports

Registered by software corporations and database vendors (Microsoft SQL 1433, MySQL 3306, PostgreSQL 5432, RDP 3389, SIP 5060).

49,152 – 65,535 Dynamic / Ephemeral

Assigned dynamically by client operating systems as source ports for outbound communication sockets, terminated when the session closes.

Security Best Practices for Ports
  • Disable Cleartext Management (Telnet 23 & HTTP 80): Replace with SSH (Port 22) with public-key authentication and HTTPS (Port 443) with valid TLS certificates.
  • Default Deny Ingress Firewall Rules: Block all inbound connections at edge firewalls; allow only explicitly required stateful return traffic and necessary public listeners.
  • Secure SNMP Infrastructure: SNMP v1 and v2c send community strings in plain text. Migrate all monitoring polling to SNMP v3 (authPriv mode) with SHA-256 and AES-256.
  • Protect Active Directory & SMB Ports: Never expose Port 445 (SMB) or Port 3389 (RDP) directly to the public internet; enforce VPN or Zero Trust Network Access (ZTNA).
