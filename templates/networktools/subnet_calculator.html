Subnetting Frequently Asked Questions

CIDR (Classless Inter-Domain Routing) replaced rigid Class A, B, and C networks in 1993. It allows networks of arbitrary size using a prefix length (e.g. /24), conserving IPv4 address space and reducing routing table sizes.

In any standard IPv4 subnet, the first address (all host bits 0) represents the Subnet/Network ID. The final address (all host bits 1) is the Directed Broadcast address. Devices cannot be assigned either, leaving 2^h - 2 usable host addresses.

RFC 3021 specifies that /31 subnets (with only 2 addresses total) can be used for point-to-point router links. Modern Cisco, Linux, and Juniper routers support this, saving 50% of the addresses previously consumed by /30 links.
