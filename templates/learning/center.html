OSI 7-Layer Reference & TCP/IP Comparison

Understand Protocol Data Units (PDUs), active network hardware devices, and transport protocols across every architectural layer.

Mnemonic: All People Seem To Need Data Processing
Layer 7
Application
PDU Unit Data
Operating Devices Web Browser, Mail Client, Host
Primary Protocols HTTP, HTTPS, DNS, SSH, DHCP, FTP, Telnet, BGP
TCP/IP: Application
Layer 6
Presentation
PDU Unit Data
Operating Devices OS Crypto Subsystem, Gateway
Primary Protocols TLS, SSL, JPEG, ASCII, MPEG, Compression
TCP/IP: Application
Layer 5
Session
PDU Unit Data
Operating Devices OS Sockets, API Sessions
Primary Protocols RPC, NetBIOS, Sockets, PPTP, NFS
TCP/IP: Application
Layer 4
Transport
PDU Unit Segment / Datagram
Operating Devices Layer 4 Load Balancer, Firewall
Primary Protocols TCP (Connection-Oriented), UDP (Connectionless)
TCP/IP: Transport

Network
PDU Unit Packet
Operating Devices Router, Layer 3 Multilayer Switch

TCP/IP: Internet

Data Link
PDU Unit Frame

Packet Encapsulation & Decapsulation Lifecycle

How a packet travels down the sending host's protocol stack (Encapsulation) and back up the receiving host (Decapsulation).

Step 1: Application Layer
User Creates Data Payload

A browser requests a webpage via HTTP GET request. The raw payload is created.

[ Data Payload: GET /index.html HTTP/1.1 ]
Step 2: Transport Layer
TCP Header Added (Segment)

Source Port (e.g. 52140) and Destination Port (80) added with sequence numbers.

[ TCP Header: Src 52140, Dst 80 ] [ Data ]
Step 3: Network Layer
IP Header Added (Packet)

Source IP (192.168.1.50) and Destination IP (192.168.1.1) added for routing.

[ IP Header: Src IP, Dst IP, TTL 64 ] [ TCP ] [ Data ]
Step 4: Data Link Layer
Ethernet Frame Header & FCS Trailer Added

Source MAC, Next-Hop Destination MAC, and CRC Frame Check Sequence trailer appended.

[ Eth Header: Src MAC, Dst MAC ] [ IP ] [ TCP ] [ Data ] [ FCS Trailer ]
Step 5: Physical Layer
Transmitted as Physical Signals (Bits)

Converted to electrical voltages on copper twisted-pair or light pulses on fiber optics.

01001100 01101111 01100001 01100100 00101110 00101110
Decapsulation on Receiver

When the destination server receives the physical bits:

  • 1. Physical Layer: Converts electrical/light signals into binary bits.
  • 2. Data Link Layer: Checks FCS checksum, validates destination MAC, strips Ethernet header.
  • 3. Network Layer: Inspects destination IP address, verifies TTL, strips IP header.
  • 4. Transport Layer: Inspects destination port (80), reassembles TCP segment, strips TCP header.
  • 5. Application Layer: Hands HTTP GET data payload directly to web server software process!
