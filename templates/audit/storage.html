Hybrid Architecture Overview

To ensure smooth operation within PythonAnywhere's 512 MB free hosting limit, Ramonet separates data across two independent tiers:

  • Server Tier (SQLite): Holds only core users, metadata catalogs, and static tutorials. Consumes < 5 MB total disk space.
  • Client Tier (Browser IndexedDB): Holds all large network topologies, device configs, cable matrices, and simulation snapshots. Browser storage does NOT consume or affect your PythonAnywhere server quota.
